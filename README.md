# The Missing Diamond

The Missing Diamond is a browser-based grammar detective game for B1 teenage learners. Players investigate a museum theft across three stages, collect evidence, and identify the culprit.

The project uses HTML, CSS, and Vanilla JavaScript. It has no external dependencies, backend, or build step.

## Run locally

Open `index.html` directly in a modern browser, or serve the project folder with any simple static web server.

## GitHub Pages and Genially

The project is ready for GitHub Pages and uses relative asset paths throughout. After publishing, its HTTPS GitHub Pages URL can be embedded in Genially using an iframe.

## Project structure

- `index.html` — game entry point
- `css/` — responsive styling and visual effects
- `js/` — questions, game logic, audio, answer ordering, and effects
- `assets/images/` — characters, backgrounds, and evidence artwork
- `assets/audio/` — background music and sound effects
- `GAME_INSTRUCTIONS.md — The Missing Diamond.md` — game specification
